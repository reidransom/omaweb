Installez l’un de ces thèmes créés par la communauté en copiant son URL GitHub et en sélectionnant Installer > Style > Thème depuis le menu Omarchy (Super + Space). Pour le supprimer, utilisez Supprimer > Thème. Vous avez créé le vôtre ? Faites-le ajouter en soumettant une pull request au dépôt omarchy-site.
