Comment basculer entre les dispositions de clavier ? #

Modifiez votre fichier ~/.config/hypr/input.lua et ajoutez ceci pour basculer entre les dispositions avec Left Alt + Right Alt :

hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle",
  },
})

La barre affichera automatiquement votre disposition de clavier actuelle dès que vous en aurez configuré plusieurs (et vous pourrez également cliquer dessus pour en changer).

Comment passer l’horloge au format 12 heures ? #

Faites un clic droit sur l’horloge dans la barre pour parcourir les formats courants, y compris ceux sur 12 heures. Vous pouvez également définir directement le format :

omarchy bar set omarchy.clock format "dddd h:mm AP"

Cela affichera Sunday 10:55 AM.

Comment changer de fuseau horaire ? #

Exécutez Mise à jour > Fuseau horaire dans le menu Omarchy et faites votre choix dans la liste. Si le fuseau horaire est correct, mais que l’horloge s’est décalée, Mise à jour > Heure redémarre la synchronisation de l’heure pour vous.

Comment changer de DNS, partager ma connexion Wi-Fi ou vérifier la vitesse de ma connexion ? #

Tout cela se trouve dans la section réseau.

Comment vérifier la vitesse de mon disque ? #

Déclencher > Test de vitesse > Test de vitesse du disque mesure en temps réel les vitesses de lecture et d’écriture de votre disque. Vous pouvez également exécuter omarchy disk speedtest depuis le terminal.

Pourquoi ne puis-je pas me connecter à mon compte Google dans Chromium ? #

La version open source standard de Chromium n’inclut pas les identifiants OAuth requis par Google pour se connecter à un compte. Exécutez Installer > Service > Compte Chromium dans le menu Omarchy pour les ajouter, redémarrez le navigateur et la connexion fonctionnera.

Comment ajouter une imprimante ? #

L’impression est configurée et opérationnelle dès le départ, et vous pouvez ajouter vous-même chaque imprimante depuis Paramètres d’impression dans le lanceur d’applications (Super + Space).

Choisissez Ajouter, puis patientez un instant pendant la recherche : une imprimante connectée en USB, ainsi que la plupart des imprimantes réseau, seront détectées automatiquement. Si la vôtre ne figure pas dans la liste, choisissez Imprimante réseau > Internet Printing Protocol (ipp) et saisissez son adresse — l’écran de l’imprimante ou sa page web vous l’indiquera. Il s’agit généralement d’une adresse comme 192.168.1.50 avec une file d’attente ipp/print. Suivant vous proposera ensuite un pilote : une imprimante moderne fonctionnera mieux avec le profil sans pilote IPP Everywhere, tandis qu’un modèle plus ancien nécessitera son propre pilote.

Faites un clic droit sur une imprimante et choisissez Définir par défaut pour indiquer celle que vos applications doivent utiliser en priorité, et Propriétés pour définir le format du papier, l’impression recto verso et la qualité.

La détection automatique, qui permet aux imprimantes du réseau d’apparaître sans avoir à les ajouter, est temporairement désactivée pendant sa refonte. C’est pourquoi vous devez effectuer vous-même la première étape ci-dessus. L’impression dans un fichier PDF fonctionne sans aucune imprimante.

Comment changer l’emplacement d’enregistrement des captures d’écran ou des enregistrements d’écran ? #

Si vous souhaitez enregistrer les captures d’écran dans ~/Pictures/Screenshots plutôt que directement dans ~/Pictures, vous pouvez ajouter ceci à un fichier situé dans ~/.config/uwsm/env.d/ (par exemple ~/.config/uwsm/env.d/capture) :

export OMARCHY_SCREENSHOT_DIR="$HOME/Pictures/Screenshots"

Vous pouvez faire de même pour les enregistrements d’écran avec OMARCHY_SCREENRECORD_DIR.

N’oubliez pas de créer le répertoire dans lequel vous souhaitez enregistrer les fichiers et de redémarrer Omarchy pour que cette modification prenne effet.

Comment faire fonctionner les haut-parleurs et la webcam de mon Apple Studio Display ? #

On pourrait penser qu’il suffit de brancher l’USB-C pour que tout fonctionne, mais ce n’est malheureusement pas le cas. La solution que j’ai trouvée pour obtenir un fonctionnement fiable consiste à utiliser le câble WJESOG DisplayPort + USB-A => USB-C. Les haut-parleurs et la webcam fonctionnent alors à merveille.

N’oubliez pas qu’Omarchy intègre le contrôle de la luminosité des écrans Apple (Studio et XDR) à l’aide des touches habituelles de réglage de la luminosité du clavier.

Comment supprimer tous les logiciels supplémentaires ? #

Si vous ne voulez pas de programmes comme Obsidian, LibreOffice ou de tout autre logiciel préinstallé, vous pouvez les supprimer très facilement.

Exécutez Supprimer > Paquet pour afficher tous les paquets installés. Vous pouvez ensuite sélectionner avec Tab les paquets que vous souhaitez supprimer, puis lancer la suppression de tous les éléments sélectionnés avec Entrée.

Vous pouvez également utiliser Supprimer > Application web depuis le menu Omarchy pour supprimer les applications web préinstallées dont vous ne voulez pas.

Vous pouvez aussi exécuter Supprimer > Préinstallations pour supprimer d’un seul coup tous les éléments supplémentaires préinstallés — applications web, interfaces utilisateur en mode texte et applications facultatives. Les raccourcis clavier qui permettaient de les lancer sont également supprimés, vous laissant ainsi un ensemble vierge de raccourcis que vous pourrez personnaliser dans ~/.config/hypr/bindings.lua.

Pour les erreurs et les éléments défectueux, consultez la section Dépannage.
