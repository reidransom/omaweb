Alternative editorer #

Omarchy leveres som standard med Neovim, men hvis du gerne vil have noget lidt mere gængs og velkendt, kan du åbne Omarchy-menuen (Super + Space) og se mulighederne under Installér > Editor. Her finder du VSCode, Cursor, Zed, Sublime Text, Helix, Vim og Emacs. Hvis du ikke finder det, du leder efter, kan du se under Installér > Pakke og undersøge, om det findes som en Arch-pakke (og hvis ikke, kan du prøve Installér > AUR for at søge i AUR).

Tematilpasning understøttes for VSCode, Cursor, VSCodium og Helix.

Du kan vælge standardsystemeditoren under Opsætning > Standardvalg > Editor.

Miljø #

Omarchy understøtter opsætning af en lang række udviklingsmiljøer via sektionen Installér > Udvikling i Omarchy-menuen (Super + Space). Du finder selvfølgelig Ruby on Rails, men også alle tre store kørselsmiljøer til JavaScript (Node.js, Bun, Deno) samt populære PHP-frameworks som Laravel og Symfony. Derudover er der også Go, Rust, Python, Java, Elixir (med Phoenix), .NET, OCaml, Zig, Clojure og Scala. Udvalget er meget bredt!

De fleste af disse miljøer administreres med Mise. Det er et værktøj, der gør det muligt at installere og køre flere versioner af et programmeringssprog på den samme maskine. Det fungerer som rbenv eller rvm til Ruby eller virtualenv til Python, men understøtter en lang række forskellige miljøer.

Hvis du eksempelvis vil installere Ruby, skal du køre mise use -g ruby. Det installerer både Ruby og angiver det som global standard. Hvis dit projekt har en .ruby-version-fil, kan du også blot køre mise i i projektets rodmappe.

Docker #

Docker behøver næppe nogen introduktion. Det giver dig mulighed for at køre isolerede containere, og Omarchy installerer alt, hvad der kræves for at bruge det effektivt, herunder selve Docker og Docker Compose.

Som standard er din bruger ikke medlem af gruppen docker. Den gruppe giver reelt root-adgang uden adgangskode — enhver i gruppen kan køre docker run -v /:/host og overtage maskinen — så et enkelt ondsindet script eller en afhængighed, der kører som dig, ville ellers kun være én kommando fra root-adgang. Derfor kører du Docker med sudo på kommandolinjen (sudo docker ps, sudo docker compose up), mens de grafiske værktøjer, der kommunikerer med daemonen — Docker TUI på Super + Shift + D og Windows VM — beder om godkendelse, når det er nødvendigt. Hvis du vil have bekvemmeligheden ved en opsætning uden sudo tilbage og forstår afvejningen, kan du aktivere den under Opsætning > Sikkerhed > Docker uden sudo (eller køre omarchy-setup-security-sudoless-docker). Efter en advarsel bliver du føjet til gruppen docker, hvorefter almindelig docker og aliaset d igen fungerer uden sudo.

Husk at prøve Lazydocker-kommandoen, som lader dig administrere dine containere i en smart TUI med Super + Shift + D. Den beder om godkendelse første gang, medmindre du har aktiveret Docker uden sudo.

Du kan konfigurere almindelige databaser til lokal udvikling i Docker via Installér > Udvikling > Docker-database i Omarchy-menuen.

GitHub CLI #

GitHub CLI giver dig mulighed for at godkende med din GitHub-konto og bruge den til at klone private repositories. Det er konfigureret som et af de mise-stubprogrammer, der indlæses efter behov, så det installerer sig selv, første gang du kører gh. Kør gh auth login for at godkende. Derefter kan du klone private repositories med gh repo clone org/repo.

Du kan også udføre en lang række andre GitHub-handlinger med denne kommando. Kør blot gh for at se alle mulighederne.

Der findes også et stubprogram til ghui, som installeres efter behov og lader dig administrere dine pull requests i en TUI. Og lazygit er forudinstalleret, hvis du også gerne vil styre selve git fra en TUI.
