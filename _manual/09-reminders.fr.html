Omarchy intègre une fonctionnalité permettant de définir de simples rappels avec un compte à rebours et un message. Vous pouvez en créer un avec Super + Ctrl + R, afficher tous les rappels définis avec Super + Ctrl + Alt + R et tous les effacer avec Super + Ctrl + Shift + R. Tout est également accessible via Déclencheur > Rappel. Vous pouvez aussi utiliser la ligne de commande avec omarchy reminder 7 'Tea ready'.
