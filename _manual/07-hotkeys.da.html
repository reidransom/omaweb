Du kan se alle de vigtigste tastaturgenveje med Super + K (Tmux-genveje med Super + Alt + K og Herdr-genveje med Super + Ctrl + K).

Navigation #

Genvejstast Funktion
Super + Space Omarchy-menuen (apps og alt andet)
Super + Alt + Space Appmenu
Super + Escape Systemmenu (slumretilstand, genstart osv.)
Super + Ctrl + L Lås computeren

Ctrl + Alt + Del Luk alle vinduer
Super + T Skift vinduet mellem flise- og flydende tilstand
Super + J Skift vinduets placering (vandret/lodret)
Super + O Skift vinduet til eller fra fastgjort og flydende tilstand
Super + L Skift mellem dwindle- og rullelayout
Super + P Skift pseudovinduesstil (naturlig kontra strakt)

Super + Alt + F Skift til fuld bredde
Super + Ctrl + F Skift til fuld skærm inde i vinduet
Super + 1/2/3/4 Gå til et bestemt arbejdsområde
Super + Tab Gå til næste arbejdsområde
Super + Shift + Tab Gå til forrige arbejdsområde
Super + Ctrl + Tab Gå til det senest brugte arbejdsområde
Super + Shift + 1/2/3/4 Flyt vinduet til et arbejdsområde
Super + Shift + Alt + 1/2/3/4 Flyt vinduet til et arbejdsområde uden at følge med
Super + S / Super + Grave Vis/skjul scratchpad
Super + Alt + S / Super + Shift + Grave Flyt vinduet til scratchpad
Super + Shift + Alt + Arrows Flyt arbejdsområder til skærmen i pilens retning

Super + Minus Udvid vinduet mod venstre
Super + Equal Formindsk vinduet fra venstre

Super + Left Mouse Træk vinduet rundt

Super + Alt + Tab Skift fremad mellem vinduer i grupperingen
Super + Alt + Shift + Tab Skift baglæns mellem vinduer i grupperingen
Super + Alt + 1/2/3/4/5 Gå til et bestemt vindue i grupperingen

Super + Ctrl + Z Zoom ind på skærmen (gentag for at zoome mere)
Super + Ctrl + Alt + Z Zoom helt ud fra skærmen
Super + / Gå frem gennem indstillingerne for skærmskalering
Super + Alt + / Gå tilbage gennem indstillingerne for skærmskalering
Alt + Tab Skift fremad mellem vinduer på det aktive arbejdsområde
Alt + Shift + Tab Skift baglæns mellem vinduer på det aktive arbejdsområde
Ctrl + Alt + Tab Flyt fokus fremad mellem skærme
Ctrl + Alt + Shift + Tab Flyt fokus baglæns mellem skærme

Universel udklipsholder #

Genvejstast Funktion
Super + C Kopiér
Super + X Klip (ikke i terminalen)
Super + V Indsæt
Super + Ctrl + V Udklipsholderadministrator

På Linux skal du normalt bruge Ctrl + Shift + C/V til at kopiere og indsætte i terminalen og Ctrl + C/V alle andre steder. Disse fælles Omarchy-genvejstaster til udklipsholderen virker overalt.

Optagelse #

Genvejstast Funktion
Super + Ctrl + C Optagelsesmenu (til tastaturer uden PrintScr-knap)
Print Screen Skærmbillede
Alt + Print Screen Skærmoptagelse
Super + Print Screen Farvevælger
Super + Ctrl + Print Screen Udtræk tekst til udklipsholderen
Super + Alt + [ Gør webcam-overlejringen mindre under optagelse
Super + Alt + ] Gør webcam-overlejringen større under optagelse
Alt + Shift + L Kopiér den aktuelle URL fra webappen eller Chromium
Alt + Shift + D Download videoen på den aktuelle side til ~/Videos
Super + Ctrl + X Start/stop diktering (kræver Installér > AI > Diktering)
F9 Tryk-for-at-tale-diktering (kræver Installér > AI > Diktering)

Ved skærmoptagelser spørger genvejstasten først, hvilken lyd du ønsker, og starter derefter optagelsen. Tryk på den igen for at stoppe. Se skærmbilleder og optagelse for nærmere oplysninger.

Alle optagelsesmuligheder er også tilgængelige under Udløs > Optagelse i Omarchy-menuen (Super + Space).

Stil #

Genvejstast Funktion
Super + Ctrl + Shift + Space Vælg et nyt tema
Super + Ctrl + Space Vælg temabaggrund
Super + Backspace Slå gennemsigtighed til eller fra for et vindue
Super + Ctrl + Backspace Slå kvadratisk format til eller fra for et enkelt vindue

Ekstra baggrundsbilleder ligger i ~/.config/omarchy/backgrounds/<theme name>. De er også tilgængelige via Installér > Stil > Baggrund i Omarchy-menuen.

Alle stilindstillinger er også tilgængelige under Stil i Omarchy-menuen (Super + Space).

Tmux #

Præfikstasten er Ctrl + Space (Ctrl + B virker også). Du kan ændre disse genveje i ~/.config/tmux/tmux.conf.
