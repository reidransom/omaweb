Extraction de texte #

Appuyez sur Super + Ctrl + PrtScr pour sélectionner une zone de l’écran et en extraire le texte. Le modèle OCR open source Tesseract convertira alors rapidement cette sélection en texte et la placera dans le presse-papiers. Il vous suffira ensuite d’appuyer sur Super + V pour la coller.

Cette fonctionnalité est très utile pour récupérer des adresses figurant au bas d’images ou des numéros de téléphone intégrés dans les titres de sites web.

Dictée #

Omarchy propose la dictée assistée par IA via Voxtype. Vous pouvez l’installer depuis le menu Omarchy via Installer > IA > Dictée. Par défaut, un modèle anglais de base occupant 150 Mo sera chargé. Vous pouvez toutefois choisir le modèle à utiliser en exécutant voxtype setup model dans le terminal. Vous pouvez également modifier tous les paramètres dans ~/.config/voxtype/config.toml.

Une fois l’installation terminée, vous pouvez dicter en maintenant F9 enfoncée ou en activant la dictée avec Super + Ctrl + X. Le texte dicté apparaîtra alors dans la zone de saisie active.
