Puces Apple M1/M2 #

Asahi Alarm est une version d’Arch destinée aux ordinateurs Apple M1/M2 et basée sur Asahi Linux. Avec un peu d’effort, vous pouvez y faire fonctionner Omarchy. Consultez le guide créé par la communauté.

Machine virtuelle Apple #

Vous pouvez également installer Omarchy dans une machine virtuelle Parallels. Le processus est assez laborieux, mais il existe aussi un guide créé par la communauté.

VirtualBox #

VirtualBox est un logiciel de virtualisation populaire. Vous pouvez également y faire fonctionner Omarchy. Mais les performances ne seront probablement pas exceptionnelles.

VMware Workstation sous Windows 11 #

Un autre logiciel de virtualisation populaire pour Windows. Omarchy y a également été installé.

Steam Deck #

Le Steam Deck fonctionne sous Arch, ce qui signifie que vous pouvez y faire tourner Omarchy. Altynbek Orumbayev propose un script d’installation complet ainsi que des explications détaillées sur la procédure à suivre. Plutôt génial, non !

NixOS #

Omarchy est en réalité l’association d’Arch et de Hyprland, mais Henry Sipp a porté l’essentiel de la configuration sur NixOS. Si vous êtes adepte de Nix, voici donc un bon point de départ. Ce projet restera peut-être ou non à jour avec les dernières évolutions d’Omarchy, mais il est tout de même vraiment intéressant !

Autre chose ! #

Si vous essayez de faire fonctionner Omarchy sur une configuration autre que celle par défaut, rejoignez le canal #omarchy-on-other sur le Discord de notre communauté.
