Neovim est une implémentation moderne de l’éditeur vi, créé par Bill Joy en 1976. C’est un éditeur modal dans lequel le mode insertion et le mode commande sont séparés, et il devient presque un superpouvoir dès que vous maîtrisez ne serait-ce qu’une partie de son ensemble incroyablement riche de commandes clavier. Mais la courbe d’apprentissage est également assez raide !

Si vous découvrez complètement l’édition à la Vim, je vous recommande de regarder la série Vim As Your Editor de ThePrimeagen sur YouTube. Elle vous enseignera les bases. Sachez simplement que, contrairement aux éditeurs grand public plus classiques, il vous faudra davantage de temps pour acquérir une maîtrise élémentaire de Vim. Mais une fois ce cap franchi, les bénéfices sont également plus importants.

Neovim est pour ainsi dire configurable à l’infini. Si vous voulez vraiment aller très loin, vous pouvez créer votre propre configuration Neovim à partir de zéro. Typecraft propose un excellent cours sur la configuration de Neovim à partir de zéro. Et ThePrimeagen en propose également un.

Mais Omarchy est livré avec une configuration Neovim complète — le paquet omarchy-nvim — soigneusement peaufinée pour présenter le meilleur de ce qu’il est possible d’obtenir dès l’installation. Sans que vous ayez à écrire une seule ligne de configuration ! Elle repose sur LazyVim, une distribution de plugins et de configurations pour Neovim. C’est génial.

Les bases de LazyVim #

Comme indiqué précédemment, je ne vais pas vous apprendre Vim dans cette courte introduction, mais je peux vous présenter quelques bases de LazyVim et vous montrer comment vous y retrouver.

Tout d’abord, Neovim utilise le concept de touche leader. C’est en quelque sorte la porte d’entrée vers toutes les commandes. LazyVim l’a définie sur Space. Il vous suffit donc d’appuyer dessus, d’attendre une seconde, et vous verrez plusieurs options expliquées directement à l’écran, comme ceci :

Voici quelques commandes de base que j’utilise tout le temps :

  • Space Space - Rechercher rapidement n’importe quel fichier dans le répertoire actuel.
  • Space S G - Rechercher dans tous les fichiers avec grep et afficher un aperçu.
  • Space E - Afficher ou masquer l’arborescence des fichiers.
  • Ctrl + W W - Passer de l’arborescence des fichiers à l’éditeur, et inversement.
  • Shift + H - Se déplacer vers la gauche parmi les onglets ouverts (Vim les appelle des buffers).
  • Shift + L - Se déplacer vers la droite parmi les onglets ouverts.
  • Space B D - Fermer un onglet.
  • Space B O - Fermer tous les onglets sauf l’onglet actuel.
  • Space G G - Lancer LazyGit dans un panneau flottant depuis le répertoire actuel.
  • Space U W - Activer ou désactiver le retour automatique à la ligne.

Lorsque vous êtes dans l’arborescence des fichiers (Space E pour l’afficher, Ctrl + W W pour y accéder), vous pouvez ajouter un nouveau fichier avec a ou un nouveau répertoire avec A. Appuyez sur ? lorsque vous êtes dans l’arborescence pour voir toutes les commandes.

Si vous voulez apprendre le langage de base de Vim, j’ai écrit un article sur la syntaxe en trois parties et sur la manière de réaliser ces formidables enchaînements de commandes !

Vous pouvez consulter toutes les commandes disponibles sur la page des raccourcis clavier de LazyVim.

Démarrer Neovim #

Vous pouvez démarrer Neovim avec Super + Shift + N (ce raccourci lance votre éditeur par défaut, qui est Neovim dès l’installation), mais il est généralement plus simple de le lancer depuis le terminal en accédant au répertoire dans lequel vous souhaitez travailler, puis en saisissant n. n est l’alias de nvim, qui ouvre par défaut le répertoire actuel. Vous pouvez ouvrir un fichier unique avec n myfile.txt.

Utiliser Neovim pour les modifications avec sudo #

Si vous devez modifier des fichiers accessibles en écriture uniquement en tant que superutilisateur, vous pouvez utiliser Neovim avec toute votre configuration de plugins en exécutant sudoedit /etc/sudoers.d/00-sudo-only-file.
