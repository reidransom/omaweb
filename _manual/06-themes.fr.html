Omarchy est fourni avec vingt-deux magnifiques thèmes. Vous pouvez passer de l’un à l’autre via Style > Thème dans le menu Omarchy (Super + Space) ou accéder directement au sélecteur de thèmes avec Super + Ctrl + Shift + Space.

Chaque thème personnalise le bureau, le terminal, neovim, l’écran d’activité (btop), Chromium et l’ensemble de l’interface Omarchy : barre supérieure, menu, notifications, OSD et écran de verrouillage. (Pour Obsidian, vous devez sélectionner manuellement le thème Omarchy via Apparence > Thèmes dans l’application).

Les thèmes disposent d’un ensemble d’images d’arrière-plan parmi lesquelles vous pouvez choisir avec Super + Ctrl + Space.

Vous trouverez encore plus de thèmes sur la page des thèmes supplémentaires, ou vous pouvez même créer votre propre thème.
