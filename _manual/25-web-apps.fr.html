Vous pouvez ajouter vos propres applications web via Installer > Application web dans le menu Omarchy (Super + Space). Le nom de l’application, son URL et l’URL de son icône vous seront demandés si celle-ci ne peut pas être récupérée via le favicon. Vous trouverez d’excellentes icônes PNG pour de nombreuses applications web populaires sur Dashboard Icons.

Elles seront ensuite accessibles depuis le lanceur d’applications (Super + Space) et utiliseront l’élégante fenêtre sans bordure des applications web.

Si vous souhaitez supprimer une application web, accédez simplement à Supprimer > Application web dans le menu Omarchy.

Il est préférable de vous connecter à tous vos comptes dans un navigateur classique avant d’utiliser les raccourcis des applications web. La fine couche d’encapsulation ne fonctionne pas bien avec 1password, il est donc plus simple de vous connecter directement au préalable.

Tous les raccourcis clavier de ces applications web peuvent être modifiés dans ~/.config/hypr/bindings.lua.

Lorsque vous êtes dans une application web, vous pouvez copier l’URL actuelle dans le presse-papiers avec Shift + Alt + L.

Par défaut, Omarchy intègre déjà un assortiment d’applications :

HEY #

HEY est un service de messagerie et de calendrier qui constitue une excellente alternative pour les personnes lassées de Gmail, Outlook ou Apple Mail. Il est conçu par 37signals, l’entreprise à l’origine d’Omarchy.

Vous pouvez lancer HEY Email avec Super + Shift + E, passer directement à la rédaction d’un nouvel e-mail avec Super + Shift + Alt + E et lancer HEY Calendar avec Super + Shift + C.

Basecamp #

Basecamp est un service de gestion de projets qui aide les petites équipes à avancer plus vite et à accomplir davantage. Au lieu d’assembler tant bien que mal un mélange de Trello, Slack, Asana, Notion ou autre, vous pouvez tout regrouper au même endroit avec Basecamp. Il est conçu par 37signals, l’entreprise à l’origine d’Omarchy.

Vous pouvez lancer Basecamp depuis le lanceur d’applications (Super + Space)

ChatGPT #

ChatGPT est le chatbot d’IA le plus populaire au monde.

Vous pouvez lancer ChatGPT avec Super + Shift + A.

Grok #

Grok est le chatbot de xAI.

Vous pouvez lancer Grok avec Super + Shift + Alt + A.

WhatsApp #

WhatsApp est l’un des services de messagerie les plus populaires au monde, et sa version web est une excellente option sous Linux.

Vous pouvez lancer WhatsApp avec Super + Shift + Alt + G.

Applications Google #

Google Messages, Google Photos, Google Maps et Google Contacts sont également inclus sous forme d’applications web.

Vous pouvez lancer Google Messages avec Super + Shift + Ctrl + G, Google Photos avec Super + Shift + P et Google Maps avec Super + Shift + S. Google Contacts est accessible depuis le lanceur d’applications (Super + Space).

X #

C’est sur X que l’actualité se fait.

Vous pouvez lancer X avec Super + Shift + X et passer directement à la rédaction d’une nouvelle publication avec Super + Shift + Alt + X.

YouTube #

YouTube est la plateforme vidéo la plus populaire au monde.

Vous pouvez lancer YouTube avec Super + Shift + Y.

Zoom #

Zoom est le système de visioconférence le plus populaire aux États-Unis. Il offre d’excellentes connexions partout dans le monde. Et des réunions de 40 minutes peuvent être organisées sans compte payant. Omarchy intègre le client web de Zoom, et les liens de réunion Zoom s’y ouvriront directement.

Vous pouvez lancer Zoom depuis le lanceur d’applications (Super + Space).

Discord #

Discord est le lieu de rencontre de la plupart des communautés de joueurs et du logiciel libre, notamment celle d’Omarchy.

Vous pouvez lancer Discord depuis le lanceur d’applications (Super + Space).
