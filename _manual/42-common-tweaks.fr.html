Voici une collection d’ajustements courants de la configuration d’Omarchy. Sachez que les mises à jour du système peuvent parfois devoir restaurer certaines configurations à leur état d’origine. Si cela se produit, vos modifications ne seront pas perdues, mais placées dans un fichier .bak situé dans le même répertoire.

Si vous faites une mauvaise manipulation, vous pouvez rétablir individuellement les configurations d’origine via Mise à jour > Configuration dans le menu Omarchy. Si vous mettez vraiment tout en vrac, vous pouvez réinitialiser toutes les configurations avec omarchy-reinstall.

Toujours afficher toutes les icônes de la zone de notification #

Par défaut, les icônes de la zone de notification, comme celles de Dropbox, 1password ou Steam, sont masquées derrière la flèche d’extension, qui les affiche lorsque vous la survolez. Si vous souhaitez qu’elles restent visibles en permanence, faites un clic droit sur la flèche d’extension pour ouvrir le gestionnaire des icônes de la zone de notification, puis épinglez les icônes que vous voulez garder visibles (vous pouvez également masquer celles que vous ne voulez jamais voir).

Coins de fenêtre arrondis #

Le design par défaut d’Omarchy utilise des coins carrés, mais si vous souhaitez l’adoucir un peu, vous pouvez modifier ~/.config/hypr/looknfeel.lua afin que l’arrondi ne soit plus commenté :

hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})

Supprimer les espaces entre les fenêtres #

Sur les écrans d’ordinateur portable, certaines personnes préfèrent ne gaspiller aucun pixel avec des espaces entre les fenêtres (ni même avec une barre supérieure, que vous pouvez masquer avec Super + Shift + Space). Vous pouvez désactiver tous les espaces et toutes les bordures avec Super + Shift + Backspace, ou les supprimer définitivement en décommentant cette section de ~/.config/hypr/looknfeel.lua :

hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
