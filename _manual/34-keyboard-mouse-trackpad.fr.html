Hyprland vous permet de configurer très précisément tous vos périphériques d’entrée. Vous pouvez rendre la répétition du clavier extrêmement rapide ou utiliser le défilement naturel sur le pavé tactile. Tous ces réglages s’effectuent dans ~/.config/hypr/input.lua, également accessible via Configuration > Périphériques d’entrée dans le menu Omarchy (Super + Space). Tout paramètre que vous y définissez remplace les valeurs par défaut d’Omarchy.

Voici un exemple :

hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })

Vous pouvez consulter toutes les options des périphériques d’entrée sur le wiki de Hyprland.

Par défaut, Omarchy utilise Verr. maj. comme touche de composition pour les émojis rapides et les autres complétions. Si vous préférez utiliser Verr. maj. pour verrouiller les majuscules, attribuez la touche de composition à une autre touche en modifiant compose:caps dans kb_options. Par exemple, ceci attribue la fonction de composition à Alt droite :

hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})

Gestes du pavé tactile #

Vous pouvez également activer les gestes du pavé tactile, comme le balayage à trois doigts pour changer d’espace de travail :

hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })

Sur les ordinateurs portables Dell XPS équipés d’un pavé tactile haptique, vous pouvez également régler l’intensité du clic sur faible, moyenne ou élevée dans Déclencheur > Matériel > Retour haptique du pavé tactile.

Saisie en chinois, en japonais et dans d’autres langues #

Omarchy exécute le framework de méthode de saisie fcitx5 à chaque session — c’est lui qui gère les séquences de composition avec Verr. maj. L’infrastructure nécessaire à la saisie de caractères non latins est donc déjà en place : installez un moteur de saisie tel que fcitx5-mozc (japonais) ou fcitx5-chinese-addons (chinois) avec omarchy pkg add, ainsi que fcitx5-configtool pour ajouter le moteur à vos méthodes de saisie et définir la touche permettant de passer de l’une à l’autre.

Utiliser ALT comme SUPER #

Sur certains claviers, il n’est pas pratique d’utiliser la touche méta principale (touche Windows/cmd) comme SUPER. Vous pouvez utiliser ALT à la place en appliquant cette modification :

hl.config({
  input = {
    kb_options = "compose:caps,shift:both_capslock_cancel,altwin:swap_alt_win",
  },
})
