Vous pouvez installer Omarchy sur une seule partition, aux côtés de Windows ou d’autres installations.

Cette méthode d’installation chiffre toujours la partition avec LUKS par défaut. Elle ne diffère donc pratiquement pas d’une installation sur l’intégralité du disque et nécessite simplement que de l’espace libre soit disponible sur celui-ci.

Libérer de l’espace sous Windows #

Pour effectuer l’installation aux côtés de Windows, saisissez disk management dans le menu Démarrer et sélectionnez l’option Créer et formater des partitions de disque dur.

Repérez la partition appropriée, faites un clic droit dessus, puis choisissez Réduire le volume.

Saisissez la quantité d’espace dont vous souhaitez réduire le volume. Notez qu’elle correspondra à la taille de votre future installation d’Omarchy, partition de démarrage comprise.

Lorsque vous avez terminé, vous devriez voir quelque chose comme ceci. Dans cet exemple, la section de 50 Go est celle sur laquelle nous installerons Omarchy.

Installer Omarchy #

Le processus d’installation d’Omarchy est pratiquement identique au processus habituel. Après avoir sélectionné votre disque, l’option Installation dans l’espace libre vous sera proposée. Sélectionnez-la pour éviter d’effacer l’intégralité du disque.

Vérifiez que tout semble correct et attendez que l’installation se termine normalement. Comme pour une installation sur l’intégralité du disque, vous pouvez également choisir ici d’effectuer une installation sans chiffrement (déconseillé).

Ajouter d’autres installations au chargeur d’amorçage #

Une fois l’installation d’Omarchy terminée, vous remarquerez que Limine est désormais le chargeur d’amorçage par défaut. Vous pouvez également y ajouter des options pour vos autres installations, comme Windows.

Pour ce faire, exécutez limine-scan et suivez les instructions afin d’ajouter les éléments de votre choix à la configuration de Limine. Au démarrage, vous verrez alors les options habituelles d’Omarchy, ainsi que le Gestionnaire de démarrage Windows ou d’autres systèmes.

BitLocker #

Il est important de noter que cette méthode d’installation n’est pas compatible avec BitLocker, car celui-ci chiffre l’intégralité du disque, et pas seulement la partition. Si un message d’erreur indique que BitLocker est activé, démarrez Windows, accédez à Paramètres -> Confidentialité et sécurité -> Chiffrement de l’appareil, puis désactivez BitLocker. Le déchiffrement du disque peut prendre un certain temps.
