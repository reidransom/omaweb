Arch offre une incroyable richesse de paquets pour presque tous les types de logiciels, grâce au dépôt officiel et à l’Arch User Repository (AUR).

Son utilisation est on ne peut plus simple. Pour installer un nouveau paquet Arch, accédez à Installer > Paquet dans le menu Omarchy (Super + Space), puis saisissez le nom du paquet souhaité. La liste de tous les paquets sera automatiquement filtrée à l’aide d’une recherche approximative. (Vous pouvez également effectuer cette opération manuellement dans le terminal avec omarchy pkg add [package]).

Vous pouvez faire de même avec l’AUR en utilisant simplement Installer > AUR. Gardez toutefois à l’esprit que l’AUR n’est pas contrôlé par l’équipe d’Arch. C’est comme RubyGems ou npm. N’importe qui peut y publier un paquet.

Pour supprimer un paquet, vous pouvez utiliser Supprimer > Paquet dans le menu Omarchy. Le paquet, ses fichiers de configuration et ses dépendances seront supprimés. (Vous pouvez également effectuer cette opération manuellement avec omarchy pkg drop [package]).
