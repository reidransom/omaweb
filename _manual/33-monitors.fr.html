Par défaut, Omarchy part du principe que vous utilisez un écran de type Retina compatible avec un facteur 2x. C’est ce qu’il vous faut pour obtenir de belles polices de programmation bien nettes. C’est ce pour quoi sont optimisés presque tous les nouveaux ordinateurs portables haut de gamme dotés d’un écran haute résolution. C’est aussi le réglage recommandé pour un écran 5K de 27” comme l’Apple Studio Display, le ProArt PA27JCV, le Samsung S9 ou le Kuycon G27P, ou pour un écran 6K de 32” comme l’Apple XDR, le ProArt PA32QCV ou le Kuycon G32P.

Mais si vous n’utilisez pas un écran avec une densité d’au moins 218 PPP, vous devrez modifier les paramètres du moniteur. Par exemple, si vous possédez un écran 4K de 27” ou 32”, vous pouvez utiliser une mise à l’échelle fractionnaire en ouvrant ~/.config/hypr/monitors.lua (via Configuration > Écrans dans le menu Omarchy) et en choisissant le réglage recommandé pour cette combinaison :

local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6

Si vous utilisez un écran 1080p ou 1440p, il vous suffira probablement d’employer une mise à l’échelle 1x, avec les valeurs suivantes :

local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1

Les modifications apportées à GDK_SCALE s’appliquent aux applications lancées après le changement (et GTK ne prend en charge que les nombres entiers ; choisissez donc l’entier le plus proche du facteur d’échelle de votre moniteur). Veillez donc à fermer les fenêtres qui restent surdimensionnées après la modification (ou fermez toutes les fenêtres avec Ctrl + Alt + Del !).

Vous pouvez également parcourir rapidement les principaux facteurs de mise à l’échelle (1x, 1.25x, 1.6x, 2x, 3x, 4x) en utilisant Super + / pour les augmenter et Super + Alt + / pour les diminuer. Si vous utilisez la configuration par défaut, ces modifications seront conservées après le redémarrage.

Agrandir ou réduire le texte #

La mise à l’échelle du moniteur modifie la taille de tous les éléments. Si vous souhaitez uniquement agrandir ou réduire le texte, un seul réglage suffit :

omarchy display text size 14

Cette commande accepte une taille en pixels comprise entre 9 et 20 et ajuste simultanément le shell Omarchy, les applications GTK et votre terminal, afin que l’ensemble du bureau conserve ses proportions. Exécutez-la sans argument pour connaître le réglage actuel, et utilisez omarchy display text size reset pour revenir à la valeur par défaut. Foot est la seule exception : il ne permet pas de recharger sa configuration, si bien que les terminaux déjà ouverts conservent leur ancienne taille jusqu’à ce que vous en ouvriez un nouveau.

Étendre et dupliquer l’affichage d’un ordinateur portable #

Lorsque vous connectez un écran externe à votre ordinateur portable, le bureau est automatiquement étendu. Vous pouvez toutefois choisir de dupliquer l’affichage à la place via Déclencheur > Matériel dans le menu Omarchy ou avec Super + Ctrl + Alt + Delete. Cette option est particulièrement utile si l’écran externe est un projecteur et que vous souhaitez afficher quelque chose tout en travaillant.

Lorsque le bureau est étendu, fermer le capot de l’ordinateur portable éteint automatiquement l’écran interne. L’ouvrir rallume l’écran. Vous pouvez également contrôler cela manuellement via Déclencheur > Matériel dans le menu Omarchy ou avec Super + Ctrl + Delete.

Organiser plusieurs écrans #

Hyprland fonctionne très bien avec plusieurs écrans. Consultez la documentation de Hyprland sur les moniteurs pour en savoir plus sur leur disposition. Vous pouvez également associer des espaces de travail précis à des moniteurs précis. Dans Omarchy, ces règles se placent dans ~/.config/hypr/monitors.lua sous forme d’entrées hl.monitor — le fichier contient des exemples commentés permettant d’attribuer à un moniteur précis une résolution, une position et une rotation.

Vous pouvez également consulter Hyprmon si vous souhaitez utiliser une interface texte pour vous aider à positionner plusieurs écrans.

Régler la luminosité #

La luminosité du moniteur se règle à l’aide des touches de fonction dédiées à son augmentation ou à sa diminution. Si vous maintenez la touche Maj enfoncée lorsque vous appuyez sur ces touches, vous passez directement à la luminosité maximale ou minimale. Les touches contrôlent l’écran actif ; les moniteurs externes compatibles DDC/CI se règlent donc de la même manière que l’écran de l’ordinateur portable.

Écrans Apple #

Si vous utilisez un écran Apple, les touches habituelles de réglage de la luminosité du clavier fonctionneront également automatiquement lorsque l’écran Apple est actif. Cela est rendu possible par la commande asdcontrol.

Notez que si vous utilisez un écran Apple XDR 6K, un écran fantôme peut apparaître dans la liste renvoyée par hyprctl monitors. Vous pouvez le désactiver avec une instruction telle que hl.monitor({ output = "DP-2", disabled = true }) via Configuration > Écrans.

Sur les machines Intel, vous devez connecter les écrans Apple à l’aide d’un câble Thunderbolt standard. Sur les autres machines dépourvues de Thunderbolt, vous devrez généralement utiliser un câble DP + USB-A -> USB-C pour que cela fonctionne.
