Lazygit #

Lazygit est une excellente alternative à une application comme GitHub Desktop, et il s’exécute dans le terminal.

Vous pouvez l’exécuter directement en vous rendant dans n’importe quel répertoire géré par Git et en lançant lazygit. Vous pouvez également l’exécuter dans Neovim, où il peut être démarré avec Space G G.

Vous passez d’un volet à l’autre avec Tab. Dans le volet Fichiers, vous sélectionnez les fichiers à ajouter à la zone de préparation avec Space, puis vous pouvez créer un nouveau commit avec c. Vous pouvez afficher toutes les commandes disponibles avec ?.

Lazydocker #

Lazydocker est conçu dans le même esprit que Lazygit et vous offre également une interface dans le terminal pour gérer vos conteneurs et vos images.

Vous pouvez le lancer avec Super + Shift + D.

Vous arrêtez un conteneur avec s, ou vous le démarrez ou redémarrez avec r. Affichez toutes les commandes avec ?.

Btop #

Btop est un élégant gestionnaire de ressources qui affiche l’utilisation de la mémoire, du processeur, du disque et du réseau. Il répertorie également tous les processus actifs et vous permet de les gérer.

Omarchy l’appelle Activité, et vous le lancez avec Super + Ctrl + T. Il s’ouvre dans une fenêtre flottante, que vous pouvez intégrer à la mosaïque avec Super + T.

Herdr #

Herdr est un gestionnaire d’espaces de travail pour terminal qui vous fournit des espaces de travail, des onglets et des volets, tout en les maintenant actifs dans une session persistante dont vous pouvez vous détacher puis reprendre ultérieurement.

Vous le lancez (ou vous vous reconnectez à votre session existante) avec Super + Ctrl + Return. Omarchy fournit une configuration Herdr qui reprend sa configuration Tmux, si bien que la touche préfixe est également Ctrl + Space. Vous pouvez parcourir tous les raccourcis clavier avec Super + Ctrl + K.

Fastfetch #

Fastfetch affiche des informations sur le système, comme la version du noyau, la durée de fonctionnement, le thème, le processeur, la mémoire et bien plus encore. Il succède au populaire outil neofetch.

Omarchy l’a intégré sous le nom À propos dans le menu Omarchy (Super + Space).

Utilisation du disque #

Lorsque le disque est plein et que vous ne savez pas ce qui occupe tout l’espace, lancez Utilisation du disque depuis le lanceur d’applications (Super + Space). Il s’agit de dua en mode interactif, lancé sur l’ensemble du système de fichiers : vous pouvez ainsi parcourir les répertoires jusqu’à trouver le responsable, les plus volumineux étant affichés en premier, puis supprimer des éléments directement depuis l’interface.

Cliamp #

Cliamp est un lecteur de musique rétro pour terminal inspiré de Winamp 2.x, avec notamment des stations de radio intégrées diffusant des rythmes lo-fi. Lancez-le avec Super + Shift + Alt + M, ou depuis la rubrique Applications du menu Omarchy. Appuyez sur ? pour afficher la liste complète des raccourcis clavier.

Et le Wi-Fi et le Bluetooth ? #

Vous ne trouverez pas d’interfaces en mode texte pour le Wi-Fi et le Bluetooth : ces tâches sont prises en charge par le shell d’Omarchy. Cliquez sur l’icône Wi-Fi dans la barre supérieure (ou appuyez sur Super + Ctrl + W) pour afficher les réseaux et vous connecter, puis cliquez sur l’icône Bluetooth (ou appuyez sur Super + Ctrl + B) pour associer et connecter des appareils. Consultez la section consacrée au réseau pour en savoir plus.

Ajouter les vôtres #

N’importe quel programme pour terminal peut être intégré comme une application à part entière. Accédez à Installer > TUI dans le menu Omarchy (Super + Space), indiquez un nom, une commande de lancement, un style de fenêtre et une icône, et il apparaîtra dans le lanceur d’applications comme n’importe quelle autre application. Vous pouvez ensuite le supprimer depuis Supprimer > TUI.
