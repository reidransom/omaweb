Vous pouvez afficher tous les principaux raccourcis clavier avec Super + K (les raccourcis Tmux avec Super + Alt + K et ceux de Herdr avec Super + Ctrl + K).

Navigation #

Raccourci clavier Fonction
Super + Space Menu Omarchy (applications et tout le reste)
Super + Alt + Space Menu des applications
Super + Escape Menu système (mise en veille, redémarrage, etc.)
Super + Ctrl + L Verrouiller l’ordinateur
Super + W ou Super + Q Fermer la fenêtre
Ctrl + Alt + Del Fermer toutes les fenêtres
Super + T Basculer la fenêtre entre le mode mosaïque et le mode flottant
Super + J Basculer la disposition de la fenêtre (horizontale/verticale)
Super + O Basculer la fenêtre en mode épinglé et flottant
Super + L Basculer entre les dispositions en mosaïque décroissante et à défilement
Super + P Basculer le style de pseudo-fenêtre (naturel ou étiré)
Super + F Passer en plein écran
Super + Alt + F Occuper toute la largeur
Super + Ctrl + F Passer en plein écran à l’intérieur de la fenêtre
Super + 1/2/3/4 Accéder à un espace de travail précis
Super + Tab Accéder à l’espace de travail suivant
Super + Shift + Tab Accéder à l’espace de travail précédent
Super + Ctrl + Tab Revenir au dernier espace de travail utilisé
Super + Shift + 1/2/3/4 Déplacer la fenêtre vers un espace de travail
Super + Shift + Alt + 1/2/3/4 Déplacer la fenêtre vers un espace de travail sans la suivre
Super + S / Super + Grave Afficher ou masquer le bloc-notes
Super + Alt + S / Super + Shift + Grave Déplacer la fenêtre vers le bloc-notes
Super + Shift + Alt + Arrows Déplacer les espaces de travail vers l’écran situé dans la direction indiquée
Super + Arrow Déplacer le focus vers la fenêtre située dans la direction de la flèche
Super + Shift + Arrow Permuter la fenêtre avec une autre située dans la direction de la flèche
Super + Minus Agrandir la fenêtre vers la gauche
Super + Equal Réduire la fenêtre par la gauche
Super + Shift + Minus Réduire la fenêtre par le haut
Super + Shift + Equal Agrandir la fenêtre vers le bas
Super + Alt + Minus/Equal Même redimensionnement par petits incréments
Super + Ctrl + Minus/Equal Même redimensionnement par grands incréments
Super + Alt + Home Enregistrer la largeur de la fenêtre
Super + Home Restaurer la largeur enregistrée de la fenêtre
Super + Left Mouse Faire glisser la fenêtre
Super + Right Mouse Redimensionner la fenêtre
Super + Scroll Wheel Faire défiler les espaces de travail
Super + G Activer ou désactiver le regroupement de fenêtres
Super + Alt + G Retirer la fenêtre du groupe
Super + Alt + Tab Parcourir les fenêtres du groupe
Super + Alt + Shift + Tab Parcourir en sens inverse les fenêtres du groupe
Super + Alt + 1/2/3/4/5 Accéder à une fenêtre précise du groupe
Super + Alt + Arrow Déplacer la fenêtre dans le groupe situé dans la direction de la flèche
Super + Ctrl + Left/Right Passer d’une fenêtre à l’autre au sein d’un groupe en mosaïque
Super + Ctrl + Z Zoomer sur l’écran (répétez pour augmenter le zoom)
Super + Ctrl + Alt + Z Dézoomer complètement l’écran
Super + / Parcourir vers l’avant les options de mise à l’échelle de l’écran
Super + Alt + / Parcourir vers l’arrière les options de mise à l’échelle de l’écran
Alt + Tab Parcourir vers l’avant les fenêtres de l’espace de travail actif
Alt + Shift + Tab Parcourir vers l’arrière les fenêtres de l’espace de travail actif
Ctrl + Alt + Tab Déplacer le focus vers l’avant entre les écrans
Ctrl + Alt + Shift + Tab Déplacer le focus vers l’arrière entre les écrans

Presse-papiers universel #

Raccourci clavier Fonction
Super + C Copier
Super + X Couper (hors du terminal)
Super + V Coller
Super + Ctrl + V Gestionnaire du presse-papiers

Sous Linux, il faut généralement utiliser Ctrl + Shift + C/V pour copier-coller dans le terminal et Ctrl + C/V partout ailleurs. Ces raccourcis du presse-papiers unifié d’Omarchy fonctionnent partout.

Alt + Shift + D Télécharger la vidéo de la page actuelle dans ~/Videos
Super + Ctrl + X Démarrer/arrêter la dictée (nécessite Installer > IA > Dictée)
F9 Dictée en mode appuyer-pour-parler (nécessite Installer > IA > Dictée)

Pour les enregistrements d’écran, le raccourci vous demande d’abord quelle source audio vous souhaitez utiliser, puis lance l’enregistrement. Utilisez-le à nouveau pour arrêter. Consultez les captures et enregistrements d’écran pour plus de détails.

Toutes les options de capture sont également accessibles sous Déclencher > Capture dans le menu Omarchy (Super + Space).

Style #

Raccourci clavier Fonction
Super + Ctrl + Shift + Space Choisir un nouveau thème
Super + Ctrl + Space Choisir l’arrière-plan du thème
Super + Backspace Activer ou désactiver la transparence d’une fenêtre
Super + Ctrl + Backspace Activer ou désactiver le format carré pour une fenêtre unique

Les images d’arrière-plan supplémentaires se trouvent dans ~/.config/omarchy/backgrounds/<theme name>. Elles sont également accessibles via Installer > Style > Arrière-plan dans le menu Omarchy.

Toutes les options de style sont également accessibles sous Style dans le menu Omarchy (Super + Space).

Tmux #

La touche de préfixe est Ctrl + Space (Ctrl + B fonctionne également). Vous pouvez modifier ces raccourcis dans ~/.config/tmux/tmux.conf.

Fonctions de disposition Tmux #

Ces fonctions doivent être exécutées au sein d’une session Tmux.

Commande Fonction

tdlm <ai> [<second_ai>] Créer une disposition de développement par sous-répertoire
tsl <count> <command> Créer une disposition en essaim à plusieurs volets
