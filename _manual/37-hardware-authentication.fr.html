Authentification par empreinte digitale #

De nombreux ordinateurs portables sont équipés d’un capteur d’empreintes digitales pour l’authentification. Vous pouvez l’utiliser avec Omarchy en sélectionnant Configuration > Sécurité > Empreinte digitale dans le menu Omarchy (Super + Space).

Cela installera le paquet de gestion des empreintes digitales, enregistrera et vérifiera votre empreinte, puis tout sera prêt pour vous permettre d’utiliser votre empreinte afin de déverrouiller l’ordinateur depuis l’écran de verrouillage (que vous pouvez afficher avec Super + Ctrl + L), de passer en mode sudo et d’autoriser les demandes du système.

Lorsque le couvercle de votre ordinateur portable est fermé, la demande d’empreinte digitale est automatiquement ignorée afin de passer directement à la demande de mot de passe, plutôt que d’attendre la réponse d’un capteur auquel vous ne pouvez pas accéder. Si vous devez utiliser un clavier externe dépourvu de capteur, appuyez simplement sur CTRL + C lorsque votre empreinte digitale vous est demandée pendant l’utilisation de sudo.

Vous pouvez supprimer l’authentification par empreinte digitale en sélectionnant Supprimer > Sécurité > Empreinte digitale dans le menu Omarchy.

Authentification Fido2 #

Si vous utilisez un appareil Fido2, vous pouvez le configurer pour l’authentification avec sudo en sélectionnant Configuration > Sécurité > Fido2 dans le menu Omarchy (Super + Space). Cela couvre l’utilisation de sudo et les demandes d’autorisation du système, mais pas le déverrouillage de votre ordinateur.

Vous pouvez supprimer l’authentification Fido2 en sélectionnant Supprimer > Sécurité > Fido2 dans le menu Omarchy.
