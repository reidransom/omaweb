Omarchy se configure principalement à l’aide de ce que l’on appelle les dotfiles, situés dans ~/.config. Ces fichiers sont les vôtres et vous pouvez les modifier. Les fichiers situés dans /usr/share/omarchy appartiennent à Omarchy lui-même et vous ne devriez pas y toucher. Si vous devez modifier quoi que ce soit dans /usr/share/omarchy, redéfinissez plutôt la valeur correspondante dans ~/.config.

Les principales configurations peuvent être modifiées directement depuis le menu Omarchy (Super + Space), par exemple via Configuration > Écrans, Configuration > Raccourcis clavier, Configuration > Périphériques d’entrée et Configuration > Config > [fichier]. En procédant ainsi, tout processus devant être redémarré après la modification d’une configuration le sera automatiquement lorsque vous quitterez l’éditeur (Neovim par défaut — :wq, souvenez-vous-en ! — mais vous pouvez changer cela via Configuration > Valeurs par défaut > Éditeur).

Voici une liste des principaux fichiers de ~/.config et de ce qu’ils contrôlent :

Fichier Rôle
~/.config/hypr/hyprland.lua La configuration principale de Hyprland. Elle charge les valeurs par défaut d’Omarchy ainsi que vos fichiers de remplacement ci-dessous. En savoir plus sur les configurations de Hyprland.
~/.config/hypr/bindings.lua Vos propres raccourcis clavier et vos remplacements des valeurs par défaut.
~/.config/hypr/monitors.lua Contrôle vos écrans, leur résolution et leur position.
~/.config/hypr/input.lua Contrôle la disposition de votre clavier ainsi que les paramètres de votre souris et de votre pavé tactile.
~/.config/hypr/looknfeel.lua Contrôle les espacements, les bordures, les animations et le reste de l’apparence.
~/.config/hypr/autostart.lua Contrôle les processus supplémentaires lancés avec la session.
~/.config/omarchy/shell.json Contrôle le shell d’Omarchy : position de la barre, disposition et widgets, ainsi que les délais de l’économiseur d’écran, du verrouillage et de l’inactivité.
~/.config/foot/foot.ini Contrôle votre terminal (foot est utilisé par défaut).
~/.XCompose Définit vos emoji en accès rapide et la saisie semi-automatique de votre nom et de votre adresse e-mail. Veillez à exécuter omarchy-restart-xcompose après toute modification.

Si vous finissez par apporter de nombreuses modifications pour personnaliser votre configuration, il est recommandé de sauvegarder tous ces dotfiles. Stow est un excellent moyen de le faire.

Lancer vos propres applications avec la session #

Si vous souhaitez lancer quelque chose à chaque connexion — un démon de synchronisation, une application de discussion ou votre propre script — ajoutez-le dans ~/.config/hypr/autostart.lua :

o.launch_on_start("my-service")

La commande est ainsi lancée dans le cadre de la session et sera donc correctement arrêtée lorsque vous vous déconnecterez.

Exécuter des scripts lors d’événements système #

Omarchy déclenche des hooks à différents moments, auxquels vous pouvez rattacher vos propres scripts. Ils se trouvent dans ~/.config/omarchy/hooks/<event>.d/, avec un répertoire par événement, et chaque fichier exécutable qui s’y trouve est lancé lorsque l’événement se produit :

Événement Moment de l’exécution
post-boot Juste après le démarrage du bureau
post-update Pendant omarchy update, après les paquets et les migrations
pre-refresh-pacman Avant que omarchy refresh pacman resynchronise la configuration des paquets
theme-set Après un changement de thème (nom du thème dans $1)
font-set Après un changement de police (nom de la police dans $1)
battery-low Lorsque le niveau de la batterie devient faible (pourcentage dans $1)

Chacun de ces répertoires contient déjà un fichier .sample illustrant la structure d’un hook : retirez .sample de son nom pour l’activer. Pour installer un script que vous avez écrit ailleurs, utilisez omarchy hook install post-boot ~/my-hook, ce qui le copie dans le répertoire et le rend exécutable.

Ajouter vos propres entrées de menu #

Vous pouvez ajouter vos propres lignes au menu Omarchy (Super + Space) en modifiant ~/.config/omarchy/extensions/omarchy-menu.jsonc. Les entrées sont identifiées par un identifiant utilisant des points, et c’est cet identifiant qui détermine leur emplacement dans l’arborescence. Ainsi, personal apparaît dans le menu racine et personal.notes apparaît à l’intérieur :

"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"omarchy-launch-editor ~/notes"},

Si vous réutilisez un identifiant existant, vous remplacez la ligne correspondante au lieu d’en ajouter une nouvelle. Tous les champs disponibles sont documentés sous forme de commentaires dans le fichier fourni.

Ajouter vos propres exportations, fonctions et alias de shell #

Omarchy est fourni avec de nombreux alias pratiques et fonctions utiles, mais il est très courant de vouloir ajouter les vôtres. Ajoutez vos alias, fonctions et exportations dans ~/.bashrc. Ce fichier ne sera pas écrasé lors des mises à jour. Si vous souhaitez modifier l’une des valeurs par défaut d’Omarchy, vous pouvez également la redéfinir ici en toute sécurité.

Modifier les fichiers internes d’Omarchy #

Après tout, c’est votre ordinateur. Vous pouvez en faire ce que vous voulez, mais je vous déconseille de modifier directement les fichiers de /usr/share/omarchy. Ils appartiennent au paquet pacman d’Omarchy : vos modifications seront donc tout simplement écrasées lors de la prochaine mise à jour. Mieux vaut plutôt redéfinir les valeurs par défaut qui ne vous conviennent pas dans le dossier ~/.config/*.

Vous pouvez ainsi modifier presque tout, notamment les raccourcis clavier par défaut. Il suffit de modifier ~/.config/hypr/bindings.lua pour, par exemple, remplacer Obsidian par Joplin (à installer avec omarchy-pkg-add joplin-bin) :

hl.unbind("SUPER + SHIFT + O")
o.bind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")

Si vous tenez absolument à bidouiller les fichiers internes d’Omarchy, passez sur le canal de développement via Mise à jour > Canal > Dev. Omarchy sera alors lié à une copie de travail git du code source dans ~/omarchy, que vous pourrez modifier à votre guise. Personne n’est là pour vous dire quoi faire !

Annuler toutes les modifications #

Si vous finissez par mettre le désordre dans les configurations, vous pouvez toujours rétablir les valeurs par défaut via Mise à jour > Configuration dans le menu Omarchy. Vous pouvez également exécuter omarchy reinstall configs pour tout réinitialiser.
