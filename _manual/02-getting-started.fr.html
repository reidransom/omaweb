Omarchy s’installe à l’aide d’une image ISO. Vous pouvez choisir entre une installation sur le disque entier, qui utilise l’intégralité du disque, ou une installation dans l’espace libre, qui place Omarchy dans l’espace non alloué d’un disque — c’est ainsi que vous pouvez configurer un double démarrage aux côtés de Windows ou d’un autre système d’exploitation (consultez l’installation en double démarrage — notez que vous devrez d’abord désactiver BitLocker dans Windows). Dans les deux cas, l’installation utilise par défaut un chiffrement intégral, et l’option d’installation sur le disque entier effacera le disque sélectionné : veillez donc à effectuer une sauvegarde avant d’utiliser un disque existant !

Commencez par télécharger l’image ISO d’Omarchy, placez-la sur une clé USB (utilisez balenaEtcher sur Mac/Windows ou caligula sous Linux), puis démarrez depuis la clé.

Vous devez désactiver le démarrage sécurisé (Secure Boot) et/ou le TPM dans le BIOS. Vous devez les désactiver pour pouvoir installer Omarchy. Il s’agit de dispositifs de sécurité Microsoft destinés à Windows et aux distributions Linux affiliées à Microsoft.

Sélectionnez ensuite un disque pour l’installation, puis détendez-vous et regardez l’installation se dérouler. Elle peut s’effectuer en moins d’une minute sur les machines modernes les plus rapides, mais ne devrait pas prendre plus de 5 minutes, même sur un ordinateur plus ancien.

Vous voilà prêt à utiliser Omarchy !

Utilisez un clavier filaire ou 2,4 GHz ! #

Le chiffrement intégral du disque ne vous permettra pas de saisir le mot de passe avec un clavier Bluetooth au démarrage. De la même manière, vous ne pouvez pas utiliser un clavier Bluetooth pour accéder au BIOS d’un PC. Vous aurez besoin d’un clavier utilisant soit un dongle 2,4 GHz, soit un câble (ce qui est de toute façon bien mieux en matière de latence !). Personnellement, j’adore le Lofree Flow84 !

Installation pour un autre propriétaire #

Si vous configurez une machine pour quelqu’un d’autre — un membre de votre famille, un nouvel employé, un acheteur — vous ne devez pas répondre aux questions personnelles à sa place. Appuyez sur Ctrl + C dès le tout premier écran du programme d’installation (celui du choix du clavier), et Omarchy vous proposera plutôt de préparer la machine pour un autre propriétaire. Le système s’installe immédiatement, mais toute la configuration personnelle — disposition du clavier, nom d’utilisateur, mot de passe — est reportée jusqu’au premier démarrage de la machine. Le disque reste chiffré par défaut, et le mot de passe choisi par le nouveau propriétaire lors de ce premier démarrage devient également le mot de passe de chiffrement. (Une machine que vous avez déjà utilisée peut également être cédée sans réinstallation — consultez la réinitialisation de l’ordinateur.)

Installations sans assistance #

L’image ISO peut également effectuer l’installation de manière entièrement autonome — sans clavier ni assistant — lorsque sa configuration lui est fournie sur un second disque. C’est la méthode à employer pour utiliser Omarchy comme image de base pour des machines virtuelles et des machines gérées en parc. Consultez les installations sans assistance.

Installations sans chiffrement #

Omarchy est installé avec le chiffrement activé par défaut. C’est le choix sûr et responsable pour tout ordinateur susceptible d’être perdu ou volé. Vous ne voulez pas qu’une personne ayant accès à votre matériel puisse accéder à vos données !

Toutefois, dans certaines circonstances particulières, par exemple pour des installations à distance d’Omarchy sur des ordinateurs protégés ou pour des installations temporaires ne contenant aucune donnée sensible, vous pourriez préférer une installation sans chiffrement. Vous pouvez appuyer sur Ctrl + C lors de la confirmation du formatage du disque pour passer à une installation sans chiffrement.

Obtenir de l’aide en cas de problème #

Si vous rencontrez un problème, vous trouverez généralement quelqu’un prêt à vous aider dans le salon #omarchy-help du Discord de la communauté.
