Hyprland giver dig mulighed for at konfigurere alle dine inputenheder meget detaljeret. Du kan gøre tastaturets gentagelseshastighed lynhurtig eller få pegefeltet til at bruge naturlig rulning. Du ændrer det hele i ~/.config/hypr/input.lua, som du også kan åbne via Opsætning > Input i Omarchy-menuen (Super + Space). Alt, hvad du angiver dér, erstatter Omarchys standardindstillinger.

Her er et eksempel:

hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })

Du kan se alle inputindstillingerne på Hyprlands wiki om input.

Som standard bruger Omarchy CapsLock som compose-tast til hurtige emojis og andre fuldførelser. Hvis du hellere vil bruge CapsLock som Caps Lock, kan du flytte compose-tasten et andet sted hen ved at ændre compose:caps i kb_options. Dette eksempel flytter compose-tasten til Right Alt:

hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})

Bevægelser på pegefeltet #

Du kan også slå pegefeltbevægelser til, såsom at stryge med tre fingre for at skifte arbejdsområde:

hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })

På bærbare Dell XPS-computere med et haptisk pegefelt kan du også indstille klikstyrken til lav, mellem eller høj under Udløser > Hardware > Pegefeltshaptik.

Indtastning på kinesisk, japansk og andre sprog #

Omarchy kører frameworket til inputmetoder fcitx5 som en del af hver session — det er det, der driver compose-sekvenserne med CapsLock. Det betyder, at infrastrukturen til ikke-latinsk input allerede er på plads: Installer en inputmotor såsom fcitx5-mozc (japansk) eller fcitx5-chinese-addons (kinesisk) med omarchy pkg add samt fcitx5-configtool for at føje motoren til dine inputmetoder og angive den tast, der skifter mellem dem.

Brug ALT som SUPER #

På nogle tastaturer er det ikke praktisk at bruge den primære metatast (Windows-/cmd-tasten) som SUPER. Du kan i stedet ændre den til ALT med denne ændring:

hl.config({
  input = {
    kb_options = "compose:caps,shift:both_capslock_cancel,altwin:swap_alt_win",
  },
})
