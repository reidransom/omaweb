En plus des outils Linux standard, Omarchy fournit également de nombreux outils de shell améliorés. Voici les principaux.

fzf #

fzf permet d’effectuer une recherche approximative de fichiers grâce à l’alias ff. Accédez à n’importe quel répertoire, saisissez ff et vous pourrez rechercher de manière approximative n’importe quel fichier de cette arborescence, tout en affichant sur la droite un aperçu des fichiers correspondant progressivement à votre recherche.

Vous pouvez utiliser Ctrl + R pour rechercher de manière approximative dans l’historique de vos commandes avec fzf.

Cet outil est également utilisé par Neovim lorsque vous saisissez Space Space.

Le manuel complet est accessible avec man fzf.

Zoxide #

Zoxide remplace cd. Il mémorise les répertoires que vous avez visités afin que vous puissiez y accéder plus facilement par la suite. Supposons que vous exécutiez une fois cd ~/.config/omarchy. La fois suivante, il vous suffira d’exécuter cd omarchy (ou même simplement cd oma) pour que Zoxide vous y conduise directement.

Le manuel complet est accessible avec man zoxide.

ripgrep #

ripgrep recherche dans le contenu des fichiers à l’aide de rg <pattern> <path>. Par exemple, rg Controller app/ trouve toutes les occurrences de Controller dans le répertoire app.

Cet outil est également utilisé par Neovim lorsque vous saisissez Space S G.

Le manuel complet est accessible avec man rg.

eza #

eza remplace ls. Il affiche le contenu des répertoires avec davantage d’informations, des couleurs et des icônes. Par défaut, eza est associé à l’alias ls. Vous pouvez également utiliser lt pour afficher une arborescence sur deux niveaux. lsa affiche également les fichiers cachés. Enfin, lta affiche une arborescence incluant les fichiers cachés.

Le manuel complet est accessible avec man eza.

fd #

fd est une alternative à find plus facile à utiliser. Utilisez fd person.rb pour rechercher un fichier nommé person.rb dans l’arborescence actuelle. fd person.rb / effectuera la recherche dans l’ensemble du système de fichiers. fd person.rb / -H recherche dans l’ensemble du système de fichiers, y compris dans les répertoires cachés.

Le manuel complet est accessible avec man fd.

bat #

bat est une version de cat dotée de la coloration syntaxique, de numéros de ligne et de la pagination. Exécutez bat somefile.rb et vous comprendrez pourquoi il est difficile de revenir en arrière. Il œuvre également discrètement ailleurs : c’est lui qui colore vos pages de manuel et génère les aperçus dans ff.

Le manuel complet est accessible avec man bat.

tldr #

tldr est l’antidote aux pages de manuel qui commencent par trois écrans d’historique avant de vous montrer un seul exemple. tldr tar vous présente les quelques commandes dont vous aviez réellement besoin.

yt-dlp #

yt-dlp télécharge des vidéos depuis YouTube et des centaines d’autres sites. yt-dlp <url> récupère la meilleure qualité disponible dans le répertoire actuel.

Le manuel complet est accessible avec man yt-dlp.

try #

try facilite la gestion d’expériences de programmation grâce à des répertoires datés. Toutes les expériences sont stockées dans ~/Work/tries et vous pouvez y accéder avec try.
