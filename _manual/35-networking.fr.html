Dans Omarchy, le réseau est géré par NetworkManager, que vous contrôlez depuis l’icône réseau de la barre supérieure ou avec Super + Ctrl + W.

Ce panneau recherche les réseaux Wi-Fi, affiche la puissance du signal et permet de s’y connecter. Pour Ethernet, vous n’avez rien à faire : branchez le câble et cela fonctionne. Si vous préférez rester dans le terminal, nmtui offre les mêmes commandes, et il existe également un groupe de commandes omarchy network.

Partager votre Wi-Fi #

Plutôt que de lire un long mot de passe à voix haute, lancez Configuration > Réseau > Code QR lorsque vous êtes connecté au Wi-Fi. Un code QR s’affiche alors à l’écran : il suffit de le scanner avec l’appareil photo d’un téléphone pour rejoindre le réseau. C’est l’une de ces fonctions que vous utiliserez plus souvent que prévu une fois que vous saurez qu’elle existe.

Si vous avez vraiment besoin du mot de passe lui-même, omarchy network password <interface> l’affiche.

DNS #

Omarchy utilise les serveurs DNS fournis par votre réseau via DHCP. Vous pouvez les remplacer pour l’ensemble de la machine dans Configuration > Réseau > DNS, où Cloudflare et Google sont accessibles en un clic. Choisissez Personnalisé pour saisir vos propres serveurs.

Depuis le terminal, omarchy dns affiche le fournisseur actuel et omarchy dns Cloudflare en définit un.

Verrouiller la bande Wi-Fi #

Si votre routeur utilise le même nom de réseau pour les bandes 2,4 GHz, 5 GHz et 6 GHz, votre ordinateur portable peut parfois rester accroché à la plus lente. omarchy network band indique la bande utilisée, et omarchy network band 5 la verrouille. Utilisez auto pour le laisser choisir à nouveau.

Cette commande verrouille la bande plutôt qu’un point d’accès particulier, ce qui vous permet de continuer à basculer normalement entre les points d’accès.

Quelle est la vitesse ? #

Déclencher > Test de vitesse > Test de vitesse du réseau mesure vos débits réels montant et descendant à l’aide de deux cadrans. Depuis le terminal, utilisez omarchy network speedtest down ou up. (Un test de vitesse du disque se trouve juste à côté dans ce menu, si vous souhaitez mesurer les performances de cet autre goulot d’étranglement.)

Le pare-feu #

Le pare-feu est activé par défaut et bloque tout le trafic entrant, à une exception près : le port 53317, afin que LocalSend fonctionne immédiatement.

SSH reste désactivé jusqu’à ce que vous l’activiez avec Configuration > Sécurité > SSHD. Cette opération démarre le démon, ouvre le port 22 en limitant le débit pour contrer les attaques par force brute et autorise une clé. Docker est également verrouillé, afin que les conteneurs ne puissent pas s’exposer accidentellement au monde entier. Consultez la section sur la sécurité pour en savoir plus.

Tailscale #

Tailscale est un VPN maillé qui permet d’accéder simplement et en toute sécurité à tous vos ordinateurs et serveurs via Internet. Installez-le avec Installer > Service > Tailscale.

Vous obtenez alors un panneau Tailscale dans la barre, qui permet de se connecter au tailnet ou de s’en déconnecter, de changer de compte et de choisir un nœud de sortie — vos propres machines et les régions Mullvad apparaissent toutes deux dans la liste. Il permet également de parcourir vos machines, et c’est là que se trouve Taildrop : sélectionnez une machine et appuyez sur s pour lui envoyer des fichiers, ou sur c, n et d pour copier respectivement son adresse IP, son nom ou son nom DNS complet. La commande équivalente dans le terminal est omarchy tailscale send <machine> [file...], et les fichiers qui vous sont envoyés sont automatiquement enregistrés dans ~/Downloads. La notification signalant leur arrivée reste affichée jusqu’à ce que vous cliquiez dessus pour les ouvrir ou que vous la fermiez. Ainsi, si un fichier arrive pendant votre absence, la notification sera toujours là à votre retour.

L’installation ajoute également une application web donnant accès à la console d’administration de Tailscale.

Quand cela ne fonctionne plus #

Avant de redémarrer, essayez de relancer uniquement le composant en cause. Mise à jour > Matériel propose des options pour le Wi-Fi, le Bluetooth, l’audio et le pavé tactile ; recharger l’un de ces composants résout la plupart des situations où « cela fonctionnait encore il y a cinq minutes ». Consultez la section dépannage.
