Fichiers #

Fichiers (Nautilus) est le gestionnaire de fichiers graphique. Super + Shift + F l’ouvre, et Super + Shift + Alt + F l’ouvre dans le répertoire courant de votre terminal, ce qui évite beaucoup de clics. Ctrl + L vous permet de saisir un chemin, tandis qu’un appui sur Space lorsque vous avez sélectionné un fichier vous en donne un aperçu rapide sans rien ouvrir.

Branchez une clé USB ou insérez une carte SD : le support est monté automatiquement et apparaît simplement dans la barre latérale. Pour les opérations plus avancées — formater un disque, vérifier son état SMART, créer des partitions — lancez Disques depuis le lanceur d’applications (Super + Space).

Le double-clic utilise des applications par défaut judicieuses : les images s’ouvrent dans imv, les vidéos dans mpv, les PDF dans Visionneur de documents et les fichiers texte brut dans Neovim.

Obsidian #

Obsidian est une application de prise de notes gratuite et très extensible qui utilise de simples fichiers Markdown pour le stockage.

Obsidian est gratuit pour tous les usages, qu’ils soient personnels, commerciaux ou à but non lucratif.

Obsidian propose également un module complémentaire payant pour la synchronisation avec les applications mobiles sur iOS et Android. (https://obsidian.md/pricing).

Vous lancez Obsidian avec Super + Shift + O. Pour utiliser la synchronisation du thème, vous devez sélectionner le thème Omarchy dans les paramètres.

Omawrite #

Omawrite est l’application d’écriture Markdown ultra-simple d’Omarchy. Pas de coffres, pas d’extensions : seulement vous et les mots.

Vous lancez Omawrite avec Super + Shift + W.

Pinta #

Pinta est un outil de retouche d’images basique, idéal pour recadrer, redimensionner et effectuer d’autres manipulations simples. N’en attendez simplement pas une alternative à Photoshop. Il dispose tout de même d’une Baguette magique et de calques !

Vous lancez Pinta depuis le lanceur d’applications (Super + Space).

Aether #

Aether est une application de création de thèmes capable d’extraire les couleurs d’une image d’arrière-plan et de les transformer en un thème complet et cohérent. C’est la façon la plus simple de créer votre propre thème.

Vous lancez Aether depuis le lanceur d’applications (Super + Space).

LocalSend #

LocalSend vous permet d’envoyer des fichiers à d’autres appareils du même réseau sur lesquels l’application est exécutée, à la manière d’AirDrop d’Apple. Comme il est multiplateforme, vous pouvez envoyer des fichiers depuis et vers Windows, macOS, Android, iOS et, bien sûr, Linux.

Vous pouvez ouvrir le menu Partager avec Super + Ctrl + S ou depuis Déclencher > Partager dans le menu Omarchy. Quatre options vous sont proposées :

  • Presse-papiers envoie tout ce que vous avez copié sous forme de fichier texte. Idéal pour transférer un lien ou un extrait vers votre téléphone sans vous l’envoyer par e-mail.
  • Fichier ouvre un sélecteur de fichiers dans lequel vous pouvez en choisir plusieurs à la fois.
  • Dossier envoie un répertoire entier.
  • Recevoir ouvre l’application LocalSend elle-même afin qu’un autre appareil puisse vous envoyer quelque chose.

La même chose fonctionne depuis le terminal avec omarchy share clipboard, omarchy share file [path] et omarchy share folder [path]. Omettez le chemin pour afficher le sélecteur.

Vous pouvez également envoyer des fichiers directement depuis le gestionnaire de fichiers : faites un clic droit sur n’importe quelle sélection dans Nautilus et choisissez Envoyer via LocalSend.

Le pare-feu d’Omarchy bloque tout par défaut, à l’exception du port de LocalSend. Cette fonctionnalité est donc opérationnelle immédiatement après une nouvelle installation. Consultez la section consacrée à la sécurité.

LibreOffice #

LibreOffice est une suite bureautique complète comprenant un traitement de texte, un tableur, un logiciel de présentation, une application de dessin et bien plus encore. Elle est compatible avec les fichiers Microsoft Office, ce qui en fait un excellent moyen d’ouvrir ces documents Word.

Vous lancez LibreOffice depuis le lanceur d’applications (Super + Space).

Omacalc #

Omacalc est la calculatrice ultra-simple d’Omarchy, qui s’ouvre dans une fenêtre flottante.

Vous lancez Omacalc avec Super + Ctrl + Q (ou avec la touche de calculatrice, si votre clavier en possède une).

Signal #

Signal est un pionnier de la messagerie chiffrée de bout en bout et une excellente solution de communication pour quiconque préfère ne pas passer par l’un des grands conglomérats technologiques.

Vous lancez Signal avec Super + Shift + G. Il ne fait pas partie de l’installation de base : la première fois que vous utiliserez ce raccourci, Omarchy vous proposera donc de l’installer (vous le trouverez également sous Installer > Service dans le menu Omarchy).

mpv #

mpv est un lecteur multimédia simple et rapide, capable de lire presque tout depuis pratiquement n’importe quelle source. Il est idéal pour regarder des vidéos.

Vous lancez mpv depuis le lanceur d’applications (Super + Space) ou simplement en double-cliquant sur une vidéo dans le gestionnaire de fichiers.

OBS Studio #

OBS Studio vous permet d’enregistrer ou de diffuser de la vidéo à partir de plusieurs sources. Vous pouvez combiner une capture d’écran, une webcam et une entrée microphone. C’est avec lui qu’ont été enregistrées les captures vidéo d’Omarchy.

Vous lancez OBS Studio depuis le lanceur d’applications (Super + Space).

Kdenlive #

Kdenlive est un excellent logiciel de montage vidéo. Il est parfait pour retravailler les vidéos produites par OBS Studio avant de les partager.

Vous lancez Kdenlive depuis le lanceur d’applications (Super + Space).

Omacut #

Omacut est l’outil de découpe vidéo ultra-simple d’Omarchy. Lorsque vous avez seulement besoin de couper le début et la fin d’un clip, il est bien plus pratique que de lancer un logiciel de montage vidéo complet.

Vous lancez Omacut depuis le lanceur d’applications (Super + Space).
