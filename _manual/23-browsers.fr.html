Omarchy est livré avec Chromium comme navigateur par défaut. Il s’agit de la version open source standard, dont le thème est assorti au reste de votre système. C’est le navigateur qui s’ouvre avec Super + Shift + Return et dans lequel s’exécute chaque application web.

Si Chromium ne vous convient pas, vous n’êtes pas obligé de le conserver. Dans le menu Omarchy, sous Installer > Navigateur, vous trouverez Chrome, Edge, Brave, Brave Origin, Firefox et Zen. Choisissez-en un : Omarchy l’installe, configure son répertoire de stratégies et lui applique votre thème actuel.

Définir un navigateur par défaut #

L’installation d’un navigateur ne suffit pas à en faire le navigateur par défaut. Une fois qu’il est installé sur la machine, accédez à Configuration > Applications par défaut > Navigateur et sélectionnez-le. Le menu ne répertorie que les navigateurs effectivement installés et indique le navigateur par défaut actuel par une coche.

Depuis le terminal, utilisez :

omarchy default browser firefox

Exécutez cette commande sans argument pour connaître le navigateur par défaut actuel. Elle configure le gestionnaire XDG : les raccourcis clavier d’Omarchy ne sont donc pas les seuls à prendre ce choix en compte. Tout ce qui ouvre un lien, d’une application de messagerie à une commande de terminal, utilise le navigateur que vous avez choisi.

Copy URL et Download Video #

Les navigateurs de la famille Chromium (Chromium lui-même, Chrome, Edge et Brave) sont fournis avec deux extensions Omarchy qui communiquent avec le reste de votre système depuis le navigateur.

Copy URL place l’adresse de l’onglet actuel dans votre presse-papiers avec Alt + Shift + L. C’est plus rapide que de cliquer dans la barre d’adresse puis de copier. Comme l’extension passe par le presse-papiers du système plutôt que par celui du navigateur, une notification Omarchy confirme l’opération et l’URL est immédiatement disponible dans l’historique du presse-papiers ainsi que dans toutes les autres applications. Un bouton est également disponible dans la barre d’outils si vous préférez cliquer.

Download Video récupère la vidéo en cours de lecture sur la page affichée avec Alt + Shift + D. L’extension transmet l’URL à yt-dlp : elle fonctionne donc sur bien d’autres sites que YouTube, et le téléchargement est enregistré dans ~/Videos. La progression s’affiche dans la même interface à l’écran que le volume et la luminosité. Elle est actualisée sur place au lieu d’empiler les notifications. Définissez OMARCHY_YTDLP_DIR si vous préférez enregistrer les fichiers ailleurs. Consultez la FAQ pour savoir où placer les variables d’environnement.

Les deux extensions communiquent avec Omarchy par l’intermédiaire d’un petit hôte de messagerie native, qui est installé automatiquement avec le navigateur. C’est ce composant qui permet à une vidéo présente sur une page web d’être enregistrée dans votre répertoire personnel et à une URL d’arriver dans votre gestionnaire de presse-papiers, ce qu’une extension classique ne peut pas faire seule.

Ces extensions sont réservées aux navigateurs de la famille Chromium. Firefox et Zen n’en bénéficient pas.

Firefox et Zen #

Firefox et Zen appartiennent à une autre famille et bénéficient donc d’une configuration différente : Omarchy installe un fichier de stratégies offrant des réglages par défaut raisonnables et active leur mode Wayland natif, indispensable pour la mise à l’échelle fractionnaire et le défilement fluide au pavé tactile.

Ils ne bénéficient pas des extensions Chromium mentionnées ci-dessus et Omarchy ne personnalise pas leur thème. Il vous appartient donc de configurer ces aspects.

Désinstaller un navigateur #

Tout navigateur installé ici peut ensuite être désinstallé sous Supprimer > Navigateur. Chromium ne figure pas dans cette liste, car il fait partie du système de base.
