Chaque thème est fourni avec son propre ensemble de fonds d’écran, et vous pouvez ajouter les vôtres dans ~/.config/omarchy/backgrounds/[theme]. Si vous souhaitez ajouter une image d’arrière-plan supplémentaire au thème nord, par exemple, il vous suffit de placer le fichier dans ~/.config/omarchy/backgrounds/nord.

Le plus simple est d’accéder à Installer > Style > Arrière-plan dans le menu Omarchy. Le dossier dans lequel sont stockés les fonds d’écran de ce thème s’ouvrira. Appuyez sur Super + Shift + F pour lancer un autre gestionnaire de fichiers, trouvez votre fond d’écran, puis copiez-le dans ce dossier. Il figurera désormais parmi les fonds d’écran que vous pouvez sélectionner à l’aide de Super + Ctrl + Space.

Vous trouverez une immense collection de fonds d’écran soigneusement sélectionnés sur https://github.com/dharmx/walls.
