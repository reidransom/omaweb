Habituellement, sous Linux, vous devez utiliser Ctrl + Maj + C/V pour copier-coller dans le terminal et Ctrl + C/V partout ailleurs. Il est difficile de s’y habituer quand on n’a pas toujours utilisé Linux ! Il en va de même pour le passage de super à ctrl si vous venez du Mac.

Omarchy résout ces deux problèmes grâce à des raccourcis unifiés pour le presse-papiers, qui fonctionnent (presque) partout. Les voici :

Raccourci clavier Commande
Super + C Copier
Super + X Couper
Super + V Coller
Super + Ctrl + V Historique du presse-papiers

Notez que la plupart des environnements d’agents utilisent Ctrl + V pour coller des images, mais Super + V pour coller du texte.

Historique du presse-papiers #

L’historique du presse-papiers est fourni par le shell Omarchy et fonctionne aussi bien avec le texte qu’avec les images. Ouvrez-le avec Super + Ctrl + V, sélectionnez l’élément souhaité avec la touche Entrée : il sera alors placé dans le presse-papiers et prêt à être collé avec Super + V.
