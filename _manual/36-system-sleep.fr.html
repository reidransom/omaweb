Omarchy active par défaut la mise en veille et la veille prolongée, mais si l’une ou l’autre pose problème sur votre machine, vous pouvez la désactiver.

Profils d’alimentation #

Sur un ordinateur portable, Omarchy mémorise séparément votre profil d’alimentation lorsque l’appareil est branché sur secteur et lorsqu’il fonctionne sur batterie, puis bascule de l’un à l’autre lorsque vous le branchez ou le débranchez. Par défaut, cela signifie le mode performances sur secteur et le mode équilibré sur batterie.

Vous pouvez voir les profils proposés par votre machine avec omarchy powerprofiles list, puis définir celui que vous souhaitez pour l’état actuel avec omarchy powerprofiles set autodetect power-saver. Pour définir l’autre état sans rien débrancher, indiquez-le directement : omarchy powerprofiles set battery power-saver. Quel que soit votre choix, ce profil sera réappliqué la prochaine fois que vous vous trouverez dans cet état.

Activer ou désactiver la mise en veille #

Vous pouvez activer ou désactiver la mise en veille en exécutant omarchy toggle suspend dans le terminal. Cette commande se contente d’afficher ou de masquer l’option sous Système (ou Super + Esc) afin que vous puissiez vérifier si elle fonctionne de manière fiable sur votre système. Si ce n’est pas le cas, vous pouvez la masquer à nouveau avec la même commande.

Activer ou désactiver la veille prolongée #

Vous pouvez configurer la veille prolongée en exécutant omarchy hibernation setup dans le terminal. La veille prolongée crée sur votre disque de démarrage un sous-volume /swap dont la taille correspond à la quantité de mémoire vive physique de votre machine ; veillez donc à disposer de suffisamment d’espace libre. Sur une machine dotée de 32GB de mémoire, vous aurez toujours besoin d’au moins 32GB+ d’espace libre pour ce volume. La veille prolongée nécessite également le chargeur de démarrage Limine par défaut.

Une fois la configuration terminée, l’option de veille prolongée apparaît sous Système (ou Super + Esc) afin que vous puissiez vérifier si elle fonctionne de manière fiable sur votre système. Si ce n’est pas le cas, vous pouvez la supprimer en exécutant omarchy hibernation remove.
