Une grande partie de ce que vous modifiez au quotidien n’est pas vraiment un réglage. Il s’agit plutôt d’un mode que vous activez pendant une heure, puis désactivez : l’éclairage nocturne quand vous travaillez tard, le mode Ne pas déranger pendant une présentation, le maintien en éveil lorsque vous regardez quelque chose. Omarchy appelle cela des options à bascule, qui fonctionnent toutes de la même manière — un raccourci clavier, une entrée de menu et une commande qui actionnent tous le même commutateur.

Le menu Basculer #

Super + Ctrl + O ouvre directement Déclencher > Basculer. Vous pouvez également y accéder depuis le menu Omarchy (Super + Space). Tout ce qui figure dans cette liste est un commutateur que vous pouvez actionner sans avoir à vous demander où son état est stocké.

Dans le terminal, ces mêmes commutateurs prennent la forme omarchy toggle <thing>. Exécutez simplement omarchy toggle pour afficher tout le groupe.

Option Raccourci clavier Commande
Éclairage nocturne Super + Ctrl + N omarchy toggle nightlight
Mettre les notifications en sourdine Super + Ctrl + , omarchy toggle notification silencing
Maintenir en éveil (aucun verrouillage en cas d’inactivité) Super + Ctrl + I omarchy toggle idle
Capture des plantages — omarchy toggle crash-capture
Économiseur d’écran — omarchy toggle screensaver
Barre de menus Super + Shift + Space omarchy toggle bar
Pavé tactile XF86TouchpadToggle omarchy toggle touchpad
Écran tactile — omarchy toggle touchscreen
Mise en veille — omarchy toggle suspend
GPU hybride — omarchy toggle hybrid gpu

Les commutateurs du pavé tactile, de l’écran tactile et du GPU hybride se trouvent sous Déclencher > Matériel (Super + Ctrl + H) plutôt que sous Basculer, puisqu’ils ne s’affichent que si vous disposez réellement du matériel correspondant. Les réglages du pavé tactile et de l’écran tactile sont conservés après un rechargement d’Hyprland — le nom du périphérique désactivé est enregistré dans un petit fichier d’état qu’Hyprland lit au démarrage afin de le désactiver de nouveau.

Le menu Basculer contient également quelques éléments qui ne sont pas des commandes omarchy toggle, mais qui se comportent de la même manière : le pourcentage de batterie dans la barre, la disposition des espaces de travail (Super + L), l’espacement entre les fenêtres (Super + Shift + Backspace) et le format carré pour une seule fenêtre (Super + Ctrl + Backspace).

La plupart ne sont que des fichiers indicateurs sous ~/.local/state/omarchy/toggles/. Si vous souhaitez tester l’un de ces états dans un script, omarchy-toggle-enabled vous fournit un code de sortie au lieu de vous obliger à rechercher le fichier :

omarchy-toggle-enabled screensaver-off && echo "screensaver is off"

Les indicateurs portent le nom de l’état désactivé — screensaver-off, suspend-off, bar-off — leur présence signifie donc que la fonctionnalité est désactivée.

Indicateurs dans la barre #

Lorsqu’un mode est activé, un petit glyphe apparaît au milieu de la barre supérieure, à côté de l’horloge. Il s’agit du widget des indicateurs, qui regroupe la dictée, l’enregistrement de l’écran, les rappels en attente, l’éclairage nocturne, le mode Ne pas déranger et le maintien en éveil.

Les indicateurs inactifs sont masqués. Survolez la zone qui les entoure pour les faire apparaître en grisé ; vous pouvez alors cliquer sur l’un d’eux pour l’activer sans connaître son raccourci clavier. Cliquer sur un indicateur actif le désactive. Si vous préférez tous les voir en permanence, définissez alwaysShow sur true dans l’entrée omarchy.indicators de ~/.config/omarchy/shell.json — consultez la barre supérieure pour savoir comment configurer ses widgets.

Éclairage nocturne #

Super + Ctrl + N réchauffe les couleurs de l’écran à 4000K ; appuyez de nouveau pour les ramener à 6500K. Cette fonction repose sur hyprsunset, que le commutateur démarre automatiquement s’il n’est pas déjà en cours d’exécution.

Par défaut, hyprsunset ne modifie absolument pas votre écran. ~/.config/hypr/hyprsunset.conf est fourni avec un profil neutre, précisément pour que l’affichage reste inchangé jusqu’à ce que vous demandiez des couleurs plus chaudes. Si vous préférez que le changement se fasse selon l’heure, remplacez-le par un profil horaire :

profile {
    time = 20:00
    temperature = 4000
}

Démarrez ensuite hyprsunset à la connexion en ajoutant o.launch_on_start("hyprsunset") à ~/.config/hypr/autostart.lua. La paire 4000K/6500K utilisée par le commutateur est fixe ; modifiez donc le fichier de configuration si vous souhaitez une autre température.

Ne pas déranger #

Super + Ctrl + , met les notifications en sourdine. Aucune bannière de notification ne s’affiche tant que ce mode est activé, et l’indicateur en forme de cloche barrée reste dans la barre pour vous rappeler pourquoi le bureau est devenu silencieux.

Rien n’est perdu pour autant. Une notification mise en sourdine est directement enregistrée dans votre historique des notifications, ce qui est exactement ce qu’il vous faut lorsque vous revenez et vous demandez ce que vous avez manqué. Ouvrez-le avec Super + Shift + Alt + ,. Consultez les notifications pour en savoir plus sur leur fonctionnement.

Deux types de messages passent malgré tout : les propres notifications de confirmation d’Omarchy pour une action que vous venez d’effectuer (« Thème modifié », « Capture d’écran enregistrée »), ainsi que les alertes critiques envoyées depuis la ligne de commande. Les applications de messagerie qui marquent tout comme critique pour s’imposer au premier plan ne sont pas concernées.

Inactivité #

Le shell Omarchy gère le comportement en cas d’inactivité, et les délais sont définis dans un bloc idle de premier niveau dans ~/.config/omarchy/shell.json :

{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}

Ces deux nombres correspondent à des secondes comptées à partir du moment où débute votre inactivité — et non l’un à partir de l’autre. Avec les valeurs par défaut, l’économiseur d’écran apparaît donc après deux minutes et demie, puis l’écran de verrouillage prend le relais après cinq minutes, que l’économiseur d’écran se soit lancé ou non. Enregistrez le fichier et le shell applique immédiatement les nouveaux délais.

Si vous quittez l’économiseur d’écran avant l’expiration du délai de verrouillage, cela compte comme une activité et le verrouillage en attente est annulé. Votre ordinateur ne se verrouille donc pas simplement parce que vous y avez jeté un coup d’œil.

Pour empêcher entièrement le verrouillage en cas d’inactivité, Super + Ctrl + I — ou omarchy toggle idle — active le maintien en éveil, et l’indicateur en forme de tasse de café apparaît dans la barre. C’est le mode à activer avant une longue présentation ou une compilation que vous souhaitez surveiller. Activez-le de nouveau pour revenir au fonctionnement normal. omarchy toggle idle status affiche l’état actuel au format JSON si vous devez l’utiliser dans un script.

Il s’agit ici du verrouillage et de l’économiseur d’écran, pas de la gestion de l’alimentation. La mise en veille et l’hibernation disposent de leur propre configuration dans la mise en veille du système.

L’économiseur d’écran #

L’économiseur d’écran d’Omarchy affiche une illustration ASCII avec des effets de texte aléatoires, à raison d’une instance par moniteur. Une touche ou un mouvement de souris suffit à le quitter.

Vous pouvez le lancer manuellement depuis Système > Économiseur d’écran (Super + Esc), ce qui force son affichage même si vous avez désactivé l’économiseur d’écran en cas d’inactivité. Aucun raccourci clavier ne lui est attribué par défaut.

omarchy toggle screensaver permet de désactiver celui qui se lance en cas d’inactivité, si vous préférez passer directement du travail à l’écran verrouillé. Cette fonction nécessite un terminal qu’elle sait configurer — Alacritty, Foot, Ghostty ou Kitty — et vous avertira si votre terminal par défaut est différent.

Vous pouvez modifier le logo affiché sous Style > Économiseur d’écran. Importez un fichier png ou svg et Omarchy le convertira en ASCII. Consultez la personnalisation de l’image de marque.

L’écran de verrouillage #

Super + Ctrl + L verrouille l’ordinateur. Cette action lance l’écran de verrouillage du shell Omarchy, éteint l’affichage, réinitialise votre disposition de clavier sur la première afin que vous ne saisissiez pas votre mot de passe avec le mauvais alphabet et — si l’application est en cours d’exécution — verrouille 1Password au passage.

L’écran de verrouillage accepte un mot de passe, ainsi qu’une empreinte digitale une fois celle-ci configurée. Cette méthode et les autres moyens de vous authentifier sont présentés dans l’authentification matérielle.
