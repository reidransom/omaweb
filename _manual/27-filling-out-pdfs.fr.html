Omarchy est fourni avec une visionneuse PDF simple et pratique appelée Visionneur de documents. C’est le programme qui ouvrira les PDF sur lesquels vous double-cliquez.

Mais vous ne pouvez utiliser Visionneur de documents que pour remplir les PDF configurés comme formulaires. Si vous devez remplir des PDF qui ne le sont pas, ou signer un PDF, vous devrez faire un clic droit sur le fichier, sélectionner Ouvrir avec…, puis choisir Xournal++.

Xournal++ vous permet d’écrire n’importe où sur un PDF à l’aide de l’outil T. Si vous devez signer un document, il vous faudra une image de votre signature ; vous pourrez alors utiliser l’outil Image pour l’insérer et la redimensionner.

Lorsque vous avez fini de remplir le PDF, utilisez Fichier > Exporter au format PDF pour enregistrer la version finale.
