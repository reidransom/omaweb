Omarchy et vos paquets sont mis à jour via Mise à jour > Omarchy dans le menu Omarchy (Super + Space).

Omarchy est lui-même installé sous forme de paquets pacman classiques provenant du dépôt de paquets Omarchy. Une mise à jour installe donc la dernière version d’Omarchy, exécute toutes les migrations en attente pour synchroniser votre système avec celle-ci, et met à jour tous les paquets système depuis le miroir Arch d’Omarchy et AUR (si vous avez installé des paquets AUR).

Lorsqu’une nouvelle version est publiée, une icône en forme de flèche circulaire apparaît à droite de l’horloge. Cliquez dessus pour lancer le processus de mise à jour.

Quatre canaux #

Omarchy est mis à jour selon quatre canaux : stable, RC, edge et dev. Les nouvelles installations utilisent par défaut le canal stable, qui suit les versions officielles, ainsi que le miroir Arch stable d’Omarchy, décalé d’un mois par rapport à la toute dernière version. Cela nous permet de détecter les nouvelles incompatibilités nécessitant des modifications de configuration avant qu’elles ne posent problème aux utilisateurs.

Si vous souhaitez toutefois nous aider à repérer ces problèmes potentiels, vous pouvez utiliser le canal edge. Vos paquets Omarchy suivront alors les toutes dernières versions de développement et vous pourrez mettre à jour les paquets Arch dès leur publication. Vous ne devriez le faire que si vous avez de l’expérience avec Linux et savez comment restaurer un système qui rencontre des problèmes.

Avant chaque nouvelle version majeure, nous effectuerons une validation finale à l’aide du canal RC. Si vous souhaitez nous aider à apporter les dernières finitions, rejoignez-nous sur le canal #omarchy-release-candidates de Discord.

Enfin, le canal dev relie directement Omarchy à une copie de travail git du code source dans ~/omarchy, associée aux paquets edge. Vous ne devriez utiliser ce canal que si vous êtes un utilisateur Linux expérimenté, que vous travaillez directement sur Omarchy et que vous êtes prêt à accepter d’éventuels dysfonctionnements.

Vous pouvez changer de canal via Mise à jour > Canal dans le menu Omarchy (ou avec omarchy-channel-set dans le terminal).

Mises à jour des micrologiciels #

Vos paquets ne sont pas les seuls éléments qui deviennent obsolètes. De nombreux ordinateurs portables et périphériques distribuent les micrologiciels du BIOS, du SSD et de la station d’accueil par l’intermédiaire du Linux Vendor Firmware Service. L’option Mise à jour > Micrologiciels du menu Omarchy récupère et installe toutes les mises à jour disponibles pour votre matériel. Elle installe fwupd lors de sa première exécution. De nombreux micrologiciels ne peuvent être installés qu’au cours d’un redémarrage ; ne soyez donc pas surpris si l’on vous demande de redémarrer.

Avertissement concernant les mises à jour directes avec pacman/yay #

Si vous connaissez déjà Arch, vous pourriez être tenté d’exécuter simplement pacman -Syu ou yay -Syu vous-même. Mais vous passeriez alors à côté de l’instantané, des migrations et des mises à jour de configuration qu’Omarchy effectue avec les nouveaux paquets. C’est pourquoi Omarchy bloque toute mise à niveau directe du système et vous invite à utiliser plutôt omarchy update. (Si vous savez vraiment ce que vous faites, le mécanisme de protection vous indiquera comment le contourner pour une seule opération.)

Revenir en arrière après une mise à jour défectueuse #

Si vous rencontrez un problème après une mise à jour, vous pouvez restaurer votre système à partir de l’instantané créé avant celle-ci. Redémarrez simplement l’ordinateur et sélectionnez, dans le menu de démarrage, l’instantané créé avant le lancement de la mise à jour.

Si vos fichiers de configuration ont été corrompus d’une manière ou d’une autre, vous pouvez également réinstaller Omarchy en exécutant omarchy reinstall dans le terminal. Cette commande réinstallera tous les paquets Omarchy par défaut, vous replacera sur le canal stable, rétrogradera les paquets trop récents et réinitialisera tous les fichiers de configuration. Notez que toutes les modifications que vous avez apportées à la configuration par défaut d’Omarchy seront alors écrasées !
